Alias email

Intégration SimpleLogin (optionnelle) pour des alias qui fonctionnent vraiment.

Coffre chiffré

Vos identités protégées par SQLCipher (AES-256). Recherche, tri, biométrie ou PIN.

📦

Export chiffré

Sauvegarde protégée par mot de passe pour migrer d'appareil. Expiration automatique des profils temporaires.

📲 Installer l'APK en 3 étapes

  1. Téléchargez le fichier .apk depuis la dernière release GitHub.
  2. Autorisez l'installation depuis des sources inconnues quand Android le demande (une seule fois).
  3. Ouvrez le fichier téléchargé — c'est installé. Les mises à jour se font par-dessus, sans perte de données.
